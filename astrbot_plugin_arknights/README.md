# 明日方舟活动监测 Demo

这是一个面向 AstrBot 的最小 Demo：

- 从 BWIKI 的“活动关卡”和“当前寻访池”页面同步数据
- 将同步结果缓存到 SQLite
- 提供活动、卡池查询
- 支持手动刷新和查看同步状态
- 插件启动后每 30 分钟自动同步一次

## 安装

将整个 `astrbot_plugin_arknights` 目录复制到 AstrBot 插件目录，然后重启 AstrBot。

本 Demo 只使用 Python 标准库，不需要额外安装依赖。

## 命令

```text
/方舟活动
/方舟卡池
/方舟全部
/方舟刷新
/方舟同步状态
```

第一次使用建议先执行：

```text
/方舟刷新
```

如果解析失败，先执行 `/方舟同步状态` 查看错误信息。Wiki 页面结构变化时，主要需要调整 `sources/bwiki.py`。

## 说明

这是一个 Demo，不承诺 BWIKI 页面永久保持相同结构。插件会保留上一次成功同步的数据；如果本次同步失败，不会删除旧数据。

当前版本只处理能识别为“开始时间 - 结束时间”的活动或卡池。无法识别时间的记录会被跳过。
